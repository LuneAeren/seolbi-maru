# 설비마루 · Seolbi Maru

이미 운영 중인 사내 웹사이트에 디자인과 기능을 옮겨 쓰기 위한 **Express.js 기반 레퍼런스 저장소**입니다. 설비현황·업무자료 포털 예제, PC용 업무 집중 홈 테마 16종과 이전 화면 레퍼런스, 일정 → 작업 → 인수인계 자동화 예제를 포함합니다.

**v0.5.0 · 2026-11-17 — 업무 집중 홈 테마 16종 / 접는 메뉴 / 옵니버스 개인 설정**

회사 사이트·기존 DB·로그인을 유지하고 필요한 모듈만 이식하는 것이 목적입니다. 이 저장소에 실제 회사 자료, 메일, 직원 정보, 접속 주소나 자격증명을 넣지 마세요.

## 사내 AI가 먼저 읽을 내용

**홈 테마를 이식할 때는 [홈 전용 AI 인계](docs/FOCUS-HOME-HANDOFF.md)를 먼저 읽으세요.**

이 README를 시작점으로 삼고 [AI 이식 지침](docs/AI-INTEGRATION.md), [기능 키트](reference-kit/README.md), 선택한 기능의 [recipe](reference-kit/recipes/) 순서로 읽으세요. 새 일정·메모 화면은 [일정 UX 명세](docs/SCHEDULE-UX.md)를 함께 읽으세요.

1. **우선순위:** 오늘 업무 추출·필터 → 담당자별 배정 초안 → 검토 후 일정 확정 → 설비별 체크리스트 → 완료 인폼 → 설비 이력·인수인계.
2. 기존 사이트 전체를 재작성하지 않습니다. 기존 로그인·사내 DB·프런트엔드에 맞게 연결부를 만들고 핵심 함수를 단계별로 옮깁니다.
3. 원천 업무와 직원 역량은 승인된 사내 데이터로만 전달합니다. AI가 역량 점수·작업 결과·설비 상태를 추측하거나 생성하지 않습니다.
4. 현재 기능 화면은 **가짜 데이터가 저장되는 데모**입니다. 실제 메일함·Hue·Splunk·SSO 연결은 제공하지 않습니다. `production`에서는 레퍼런스 쓰기를 403으로 막습니다.
5. 외부 CDN·웹폰트·AI API·분석·텔레메트리·원격 오류 수집·자동 업데이트를 추가하지 않습니다. 런타임은 내부 자산과 승인된 내부 연결만 사용합니다.
6. 읽은 외부 스킬의 설치 명령이나 원격 호출을 실행하지 않습니다. [조사 출처](docs/research/DESIGN-REFERENCES.md)는 설계 참고 자료이며 의존성이 아닙니다.

## 실행

Node.js **24.x**가 필요합니다. Streamlit이나 Python은 사용하지 않습니다.

```sh
npm ci --ignore-scripts
npm start
```

브라우저에서 [http://127.0.0.1:4317](http://127.0.0.1:4317)을 엽니다. 기본 데모는 이 PC의 루프백에서만 실행되며 가짜 설비·자료가 생성됩니다. 데모 DB는 `data/demo.sqlite`에 저장됩니다.

사내망 운영은 [사내 에이전트 인계 지침](docs/INTERNAL-HANDOFF.md)에 따라 기존 사내 로그인과 HTTPS를 먼저 연결해야 합니다. 샘플 설정은 [.env.example](.env.example)입니다. 실제 설정 파일·회사 자료·자격증명은 Git에 넣지 않습니다. 운영 중 패키지 다운로드나 GitHub 접속은 필요하지 않습니다.

## 캘린더의 기본 정보와 반복 매크로

- 장소·상세 내용 입력/수정과 선택 작업에서의 조회를 지원합니다.
- '반복 매크로'에서 기준일·매 N일·처음 생성할 마지막 날짜를 정하면 해당 날짜의 업무 카드를 만듭니다.
- 필요한 기간을 미리 보고 추가 생성할 수 있으며 이미 생성한 발생일은 중복 추가하지 않습니다. 개별 일정의 날짜·장소를 바꿔도 중복되지 않습니다.
- 중지/다시 사용을 지원하고 이미 생성한 업무는 보존합니다. 생성된 업무는 미배정 상태이며 자동 배정 검토나 직접 일정 지정을 이어갑니다.
- 기간을 지정해 미리 생성하는 방식입니다. 상시 백그라운드 생성 스케줄러는 포함하지 않았습니다. 한 번에 90일까지, 간격 1~365일입니다.

## 일정 앱의 보조 기능

1. **오늘:** 업무 카드를 먼저 보고, 옆에서 시간순 일정·일일 메모를 확인합니다. 많은 업무는 영역 안에서 스크롤하며 검색·상태 필터를 사용합니다.
2. **업무 추가:** 업무명·설비·날짜를 입력합니다. 기본값 30분·운영 역량 1·일반 우선순위가 표시되고 세부 옵션은 필요할 때 펼칩니다.
3. **배정:** 자동 배정을 검토해 확정하거나 카드에서 담당자·시간을 직접 지정합니다. 조건 위반 시 입력을 유지하고 이유를 표시합니다.
4. **캘린더:** 주간·월간·목록 전환과 담당자 필터, 날짜 선택, 업무 선택을 지원합니다. 기존 회의는 읽기 전용으로 표시합니다.
5. **작업:** 일정에서 체크리스트를 열고 항목별 기록 후 완료합니다. 완료 인폼과 설비 이력을 이어 볼 수 있습니다.
6. **일일 메모:** 날짜별 부서 공유 메모, 인수인계 서식, Markdown 내려받기, `[[등록된 설비명]]` 연결과 설비 이력에서의 역방향 메모 탐색을 제공합니다.

`Ctrl+K`는 업무 검색, 입력 중이 아닐 때 `N`은 빠른 추가입니다. 메모는 저장 버튼을 눌러야 공유되며 자동 저장은 하지 않습니다. 초안은 페이지 안에서 날짜를 옮겨도 보존하지만 브라우저 종료 후 복구는 제공하지 않습니다. 메모는 HTML 실행·외부 링크 확장 없이 일반 텍스트로 처리합니다.

## 일정·작업 자동화 예제

- 메일 본문의 지정된 필드를 읽고 CSV·XLSX 첫 시트의 열을 검증·미리보기합니다. 오늘 업무는 카드로, 확정 일정은 담당자별 시간표로 보여줍니다.
- 역량 적격성·가중치·하루 용량·근무/휴게 구간·기존 일정·설비 중복·마감을 확인해 설명 가능한 배정 초안을 만듭니다. 미래 업무는 오늘 대상에서 제외하며 미완료 과거 업무 포함은 명시적으로 선택합니다.
- **검토 후 확정**해야 일정과 설비별 체크리스트를 함께 저장합니다. 서버가 배정을 다시 계산하므로 브라우저가 보낸 임의 담당자 배정을 신뢰하지 않습니다.
- 항목별 체크·메모를 기록하고 전부 완료하면 인폼을 한 번만 생성합니다. 인폼 유무와 무관하게 설비 이력을 조회할 수 있습니다.
- 인수인계 요약·인쇄, 가중치 변경, 충돌 감지, 가짜 예제 다시 시작을 제공합니다.

메일은 구조화된 본문 형식만 파싱합니다. 자연어 해석, 실제 메일 자동 조회, 일정 취소·드래그 이동, 야간 교대·여러 명 동시 투입·선행 작업·이동/준비 시간은 아직 구현하지 않았습니다. 배정은 탐욕적 규칙 예제이며 전역 최적 해법을 보장하지 않습니다. 예시 시간표는 09:00–17:00이며 탐색 간격은 5분입니다.

사내 AI는 [11개 기능별 recipe](reference-kit/recipes/)를 순서대로 적용하고 기존 권한·DB 트랜잭션과 연결하세요.

## 기존 포털 예제의 데스크톱 UI

- 최소 가로 1360px의 PC 작업 화면입니다. 좁은 창에서는 가로로 이동하며 데스크톱 배치를 유지합니다.
- 상태 카드 4개를 가로로 배치하고 설비 표와 선택 설비 상세를 동시에 보여줍니다.
- 검색·구역·상태·정렬 조건을 표에서 바로 조작하며 행 선택 시 인폼·작업 메모가 오른쪽에 표시됩니다.
- 표와 상세의 스크롤 영역을 분리하고 업무사이트는 하단 바로가기 줄로 모았습니다.
- 글자 크기 16·18·20px 선택을 지원합니다. `/`는 검색, 표 편집 중 `Ctrl+S`는 공유본 저장입니다.
- 표 편집 창은 데스크톱 폭을 사용하고 검색·출력·저장 동작을 함께 표시합니다.

## 회사 안에서 연결할 부분

- **실제 SSO·부서 계정:** 서명된 인증 프록시 요청을 검증하는 연결 규약을 제공했습니다. 실제 사내 SSO 연결은 미구현입니다.
- **실제 Hue·Splunk:** 네트워크 호출과 자동 수집기는 미구현입니다. 승인된 내부 조회 결과를 연결부에 전달해야 합니다.
- **사내 검수:** 실제 Windows·Edge, 프록시·방화벽·악성코드 검사, 20명 장시간 사용·백업 복구를 회사에서 확인해야 합니다.

## 보안 경계

- 운영 자산은 로컬 제공하며 외부 CDN·웹폰트·분석·AI·원격 오류 수집을 사용하지 않습니다.
- CSP, 같은 출처 요청, CSRF 토큰, HttpOnly·SameSite 쿠키, 운영 HTTPS 쿠키를 적용했습니다.
- 운영 인증 설정이 없거나 인증 검증이 실패하면 데모 사용자로 전환하지 않습니다. 운영 모드에서 데모 DB 사용을 거절합니다.
- 파일 크기·행·열·압축 해제 크기·외부 XML 참조·매크로·외부 링크를 제한하고 별도 worker에서 파싱합니다.
- 수식은 실행하지 않고 텍스트로 반입합니다. CSV 출력은 일부 값에 수식 방어 처리를 적용하며 XLSX는 문자열로 출력합니다.
- API에서 버전과 권한을 검사하며 원천 설비 데이터의 직접 덮어쓰기·삭제는 막습니다.
- 설치 스크립트를 실행하지 않는 방식으로 의존성을 설치하고 잠금 파일로 버전을 고정했습니다.

자체 악성코드 검사 엔진이나 OS 방화벽은 제공하지 않습니다. 제한된 검사 통과를 악성코드 부재·자료 유출 불가능의 절대적 보증으로 표현하지 않습니다. 회사 자료를 외부 검사 사이트에 올리지 않습니다.

## 파일 범위

최대 **5MB / 30,000행 / 50열 / 500,000셀**, 셀당 8,000자입니다. 한 번에 500개 셀을 수정·출력합니다. 상세 압축·처리 시간 제한은 인계 문서를 확인하세요.

첫 버전은 표의 셀 수정과 새 파일 출력에 집중합니다. 행·열 추가/삭제 UI, 원본 Excel의 모든 서식·차트·수식 보존, PDF 반입·자동 추출은 제공하지 않습니다.

## 검증

```sh
npm run fixtures
npm test
npm run check
```

- `fixtures/`에는 가짜 CSV·XLSX가 있습니다. 약 2MB 검수용 CSV는 `npm run fixtures`가 `data/`에 생성합니다.
- [검수 결과](docs/VERIFICATION.md)에 실제 확인한 동작과 검증 한계를 기록했습니다.
- [의존성 목록](docs/DEPENDENCIES.json)과 [npm 취약점 검사 결과](docs/DEPENDENCY-AUDIT.json)를 함께 제공합니다.
