# 설비마루 · Seolbi Maru

설비현황, 설비 인폼, 업무자료와 업무사이트를 한곳에서 확인하는 사내 업무 포털.

**설비마루**는 설비 업무를 함께 살피고 자료를 모으는 공간이라는 뜻입니다.

- 저장소 이름: `seolbi-maru`
- 문서 기준일: 2026-11-14
- 현재 단계: **개발계획 v1.0 정리 완료 / 애플리케이션 구현 전**
- 전체 계획: [개발계획과 사내 에이전트 인계 기준](docs/PLAN.md)

## 사용 환경

| 항목 | 확인된 요구사항 |
| --- | --- |
| 사용자 | 설비 엔지니어와 부서원 약 20명 |
| 운영 | 사내 웹서버, 사내망 공유 |
| 클라이언트 | Windows · Microsoft Edge |
| 기존 기술 | Streamlit · Express.js |
| 주요 데이터 출처 | Hue · Splunk |
| 인증 | 기존 사내 계정 로그인 활용 |
| 편집 | 부서원 전체 편집, 변경 이력과 충돌 처리 |
| 파일 | 주로 약 2MB의 텍스트 중심 CSV, Excel 표 반입·편집·출력 |

## 첫 버전에서 만들 기능

| 화면 | 내용 |
| --- | --- |
| 오늘 업무 | 설비현황 요약 카드, 상태별 설비 표, 최근 설비 인폼 |
| 설비 상세 | 선택한 설비의 인폼, 작업 메모, 관련 자료와 업무사이트 |
| 업무자료 | 분류·검색·필터·표 미리보기·편집·파일 다운로드 |
| 업무사이트 | 분류별 바로가기 카드와 즐겨찾기 |
| 자료·링크 편집 | 업로드·열 매핑·검증·공유본 저장·이력·복구 |

설비 상태명과 집계 규칙은 사내에서 설정합니다. 조회 실패·수집 누락·오래된 데이터는 각각 표시하며, 데이터가 없다는 이유로 설비를 정상으로 집계하지 않습니다.

## CSV·Excel 처리 흐름

1. 원본 파일 업로드 및 보존
2. 시트·인코딩·열 매핑 확인
3. 자료형·필수값·중복·파일 크기 등 검증
4. 표에서 데이터 수정
5. 새 CSV·XLSX 다운로드 또는 부서 공유본 저장
6. 변경 이력 확인과 이전 버전 복구

셀 수정, 다운로드, 부서 공유본 저장을 구분합니다. 같은 버전을 두 사람이 수정하면 먼저 저장된 내용을 자동으로 덮어쓰지 않고 충돌을 표시합니다.

Excel은 표 데이터를 편집해 새 파일을 생성하는 범위입니다. 원본 통합문서의 모든 서식·차트·수식·매크로를 보존하는 편집기는 포함하지 않습니다. PDF 자동 표 추출·편집은 추가 검토 범위입니다.

## 구성 제안

| 구성 | 역할 |
| --- | --- |
| 사내 인증 계층 | 기존 사내 계정 로그인과 부서 접근 제어 |
| Streamlit | 카드·표·설비 인폼·자료 편집 화면 |
| Express.js | 내부 API·권한 검사·공유 저장·버전 검사·변경 이력 |
| 사내 저장소 | 포털 데이터·원본 파일·편집 버전 보관 |
| 내부 연결부 | 승인된 Hue·Splunk 조회 경로와 데이터 매핑 |

실제 버전·배치·저장 계층·신원 전달 방식은 사내 에이전트가 확인합니다. 기존 기능의 재사용을 우선합니다.

## 개발과 회사 데이터의 경계

- 이 저장소에는 범용 소스·가짜 데이터·문서만 포함합니다. 현재는 계획 문서만 있습니다.
- 회사 업무자료·내부 주소·사용자 명단·자격증명·실데이터 로그는 포함하지 않습니다.
- 실제 사내 계정·Hue·Splunk·파일 경로는 사내에서 연결합니다.
- GitHub는 코드 반입 경로로 사용하며 운영 사이트가 GitHub를 자동 조회할 필요가 없도록 설계합니다.
- 사내 에이전트도 회사가 허용한 통신·실행 범위에서 사용합니다.

## 보안 구현·검수 기준

다음은 **앞으로 구현하고 검증할 기준**입니다. 보안 검증 완료를 뜻하지 않습니다.

- 운영 자산을 내부에서 제공하고 외부 CDN·웹폰트·분석·AI·오류 수집 호출을 제거합니다.
- Streamlit 사용 통계 전송을 끄고 최종 적용 설정과 실제 통신을 확인합니다.
- 기존 사내 로그인의 신뢰할 사용자 식별자를 서버 권한 검사와 편집 이력에 사용합니다.
- 업로드 형식·내용·크기·파일명·경로를 검증하고 원본 파일을 실행 경로와 분리합니다.
- 수식·매크로·외부 링크를 실행하거나 갱신하지 않도록 파일 처리 범위를 제한합니다.
- 허용된 내부 연결만 사용하고 브라우저와 서버 양쪽에서 외부 통신 시도 여부를 검사합니다.
- 소스·의존성·실제 배포 파일을 검토하고 회사 검사 도구로 검수합니다.

검사 결과, 검사 범위, 남은 제한을 기록합니다. 자동 검사 통과를 악성코드 부재의 절대적 보증으로 표현하지 않습니다.
