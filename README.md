# 설비마루 · Seolbi Maru

설비현황, 설비 인폼, 업무자료와 업무사이트를 한곳에 모으는 **Express.js 기반 사내 업무 포털**입니다.

**v0.1.1 · 2026-11-15 — 데스크톱 업무 화면 개선**

## 실행

Node.js **24.x**가 필요합니다. Streamlit이나 Python은 사용하지 않습니다.

```sh
npm ci --ignore-scripts
npm start
```

브라우저에서 [http://127.0.0.1:4317](http://127.0.0.1:4317)을 엽니다. 기본 데모는 이 PC의 루프백에서만 실행되며 가짜 설비·자료가 생성됩니다. 데모 DB는 `data/demo.sqlite`에 저장됩니다.

사내망 운영은 [사내 에이전트 인계 지침](docs/INTERNAL-HANDOFF.md)에 따라 기존 사내 로그인과 HTTPS를 먼저 연결해야 합니다. 샘플 설정은 [.env.example](.env.example)입니다. 실제 설정 파일·회사 자료·자격증명은 Git에 넣지 않습니다. 운영 중 패키지 다운로드나 GitHub 접속은 필요하지 않습니다.

## 데스크톱 UI

- 최소 가로 1360px의 PC 작업 화면입니다. 좁은 창에서는 가로로 이동하며 데스크톱 배치를 유지합니다.
- 상태 카드 4개를 가로로 배치하고 설비 표와 선택 설비 상세를 동시에 보여줍니다.
- 검색·구역·상태·정렬 조건을 표에서 바로 조작하며 행 선택 시 인폼·작업 메모가 오른쪽에 표시됩니다.
- 표와 상세의 스크롤 영역을 분리하고 업무사이트는 하단 바로가기 줄로 모았습니다.
- 글자 크기 16·18·20px 선택을 지원합니다. `/`는 검색, 표 편집 중 `Ctrl+S`는 공유본 저장입니다.
- 표 편집 창은 데스크톱 폭을 사용하고 검색·출력·저장 동작을 함께 표시합니다.

## 구현한 기능

| 화면·기능 | 내용 |
| --- | --- |
| 오늘 업무 | 설비 상태 카드, 상태·구역·검색 필터, 최근 인폼, 업무사이트, 출처별 연결 상태 |
| 설비 상세 | 연결 인폼·작업 메모, 수동 설비 정보 편집 |
| 설비 인폼 | 등록·편집·삭제, 설비 연결, 적용·만료 시각 |
| 업무자료 | CSV·XLSX 반입, 시트 선택, 열 이름 매핑, 표 검색·페이지 조회·셀 편집 |
| 파일 출력 | 미저장 수정본을 새 CSV·XLSX로 다운로드, 업로드 원본 보존 |
| 공동 편집 | 부서 공유본 저장, 버전 충돌 거절, 미저장 이탈 확인, 세션 만료 후 재시도 안내 |
| 변경 이력 | 작성자·시각·사유·버전, 삭제 상태 표시와 이전 버전 복구 |
| 업무사이트 | 사내 허용 주소 검사, 등록·편집·삭제, 브라우저별 즐겨찾기 |
| 공유 저장 | SQLite 트랜잭션, 서버 재시작 후 자료 보존 |
| 내부 연결 준비 | Hue·Splunk 비활성 계약, 전체 스냅샷 검증·원자적 반영·실패 시 정상본 유지 |

기준 시각이 설정 시간(초기 30분)을 넘긴 설비는 화면에서 확인불가로 집계하고 이전 상태를 별도 표시합니다. 실제 현장 기준은 사내에서 조정합니다. 가짜 자료를 실시간 설비현황으로 표시하지 않습니다.

## 회사 안에서 연결할 부분

- **실제 SSO·부서 계정:** 서명된 인증 프록시 요청을 검증하는 연결 규약을 제공했습니다. 실제 사내 SSO 연결은 미구현입니다.
- **실제 Hue·Splunk:** 네트워크 호출과 자동 수집기는 미구현입니다. 승인된 내부 조회 결과를 연결부에 전달해야 합니다.
- **사내 검수:** 실제 Windows·Edge, 프록시·방화벽·악성코드 검사, 20명 장시간 사용·백업 복구를 회사에서 확인해야 합니다.

## 보안 경계

- 운영 자산은 로컬 제공하며 외부 CDN·웹폰트·분석·AI·원격 오류 수집을 사용하지 않습니다.
- CSP, 같은 출처 요청, CSRF 토큰, HttpOnly·SameSite 쿠키, 운영 HTTPS 쿠키를 적용했습니다.
- 운영 인증 설정이 없거나 인증 검증이 실패하면 데모 사용자로 전환하지 않습니다. 운영 모드에서 데모 DB 사용을 거절합니다.
- 파일 크기·행·열·압축 해제 크기·외부 XML 참조·매크로·외부 링크를 제한하고 별도 worker에서 파싱합니다.
- 수식은 실행하지 않고 텍스트로 반입합니다. CSV 출력은 일부 값에 수식 방어 처리를 적용하며 XLSX는 문자열로 출력합니다.
- API에서 버전과 권한을 검사하며 원천 설비 데이터의 직접 덮어쓰기·삭제는 막습니다.
- 설치 스크립트를 실행하지 않는 방식으로 의존성을 설치하고 잠금 파일로 버전을 고정했습니다.

자체 악성코드 검사 엔진이나 OS 방화벽은 제공하지 않습니다. 제한된 검사 통과를 악성코드 부재·자료 유출 불가능의 절대적 보증으로 표현하지 않습니다. 회사 자료를 외부 검사 사이트에 올리지 않습니다.

## 파일 범위

최대 **5MB / 30,000행 / 50열 / 500,000셀**, 셀당 8,000자입니다. 한 번에 500개 셀을 수정·출력합니다. 상세 압축·처리 시간 제한은 인계 문서를 확인하세요.

첫 버전은 표의 셀 수정과 새 파일 출력에 집중합니다. 행·열 추가/삭제 UI, 원본 Excel의 모든 서식·차트·수식 보존, PDF 반입·자동 추출은 제공하지 않습니다.

## 검증

```sh
npm run fixtures
npm test
npm run check
```

- `fixtures/`에는 가짜 CSV·XLSX가 있습니다. 약 2MB 검수용 CSV는 `npm run fixtures`가 `data/`에 생성합니다.
- [검수 결과](docs/VERIFICATION.md)에 실제 확인한 동작과 검증 한계를 기록했습니다.
- [의존성 목록](docs/DEPENDENCIES.json)과 [npm 취약점 검사 결과](docs/DEPENDENCY-AUDIT.json)를 함께 제공합니다.

## 구조

```text
src/          Express API, 인증, SQLite 저장, 파일 처리, 내부 연결 계약
public/       외부 자산 없는 HTML·CSS·JavaScript 화면
fixtures/     가짜 검수 파일
scripts/      가짜 파일 생성과 소스 정책 검사
test/         보안·버전 충돌·파일·지속성·스냅샷 테스트
docs/         계획, 사내 인계, 검수와 의존성 정보
data/         실행 시 생성되는 DB·검수 파일 (Git 제외)
```
