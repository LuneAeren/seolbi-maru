# 업무 집중 홈 테마 16종 · v0.5.0

최신 사용자 요구에 따라 **같은 홈 정보 구조에서 배경·재질·색감을 비교**한다. 캘린더 시안이 아니다. v0.4의 서로 다른 홈 UX 16안은 이전 참고자료이며 [이전 기준](archive/HOME-DESIGN-v04.md)에 보존했다.

## 고정할 구조

- 왼쪽 접는 메뉴: 홈 / 업무 / 데이터허브 / 데이터 분석. 그 아래 기타 링크 4개는 연결하지 않은 더미 버튼이다.
- 메뉴 하단 옵니버스: 개인 설정을 한 곳에서 조작한다. 메뉴를 접어도 버튼과 접근 가능한 이름을 유지한다.
- 홈 첫 줄: 오늘 업무 12건·진행 4건·완료 5건·대기 3건의 가짜 수량. 선택하면 상태별 업무 목록으로 이동한다.
- 핵심 표: 설비 호기와 메인·챔버 A/B·LP 1/2. 녹색 정상 / 노랑 점검 / 빨강 정지 / 회색 미확인, 색과 상태명을 함께 표시한다.
- 보조 영역: 먼저 확인할 항목 / 오늘 업무 요약 / 최근 자료. 세 영역은 개별로 끌 수 있고 집중 모드는 핵심 수량·설비 표만 남긴다.
- 정보가 늘어나도 표·보조 위젯 안에서 스크롤한다. 설비/업무 상세는 선택했을 때 연다.

01만 기본 움직임을 켠다. 배경은 70초 주기의 작은 이동이며 카드·글자·신호등은 움직이거나 점멸하지 않는다. 다른 테마에서도 개인 설정으로 켤 수 있다. 시스템의 `prefers-reduced-motion`, 집중 모드, 비활성 페이지는 배경을 멈춘다.

02는 사용자가 말한 애플 골든브릿지를 **macOS를 연상시키는 투명 위젯과 자체 제작 브리지 풍경**으로 해석한 시안이다. Apple의 공식 테마·배경 파일을 복제하지 않았다. 브리지와 산맥은 저장소 안의 자체 SVG이며 외부 이미지 다운로드가 없다.

## 읽기와 조작

본문/컨트롤 16px, 보조 정보 최소 14px. 개인 설정에서 18/20px를 제공한다. 정보 간격은 여백만 바꾸며 글자를 줄이지 않는다. 최소 폭 1280px인 PC 화면이다. 투명도 줄이기·위젯 선명도·배경 밝기를 제공하며 불투명 표면으로 전환할 수 있다.

GitHub에서 이미 반입한 Anthropic frontend-design과 Impeccable의 위계·일관성·장식 절제 원칙을 적용했다. [출처·라이선스](research/DESIGN-REFERENCES.md)와 스킬 원문은 보존하며 원격 설치기·실행 파일은 사용하지 않는다. 실제 연결 방법은 [사내 AI 인계](FOCUS-HOME-HANDOFF.md)를 읽는다.
