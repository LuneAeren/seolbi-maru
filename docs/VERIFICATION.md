- ER 6종·선그래프 4종의 HTML/SVG/JSON/MD/Python 참고 파일과 번호 선택형 Streamlit 예제, 선택적 Plotly 단일 맵 figure 딕셔너리를 추가했다. 가짜 정규화 13점·가짜 측정 순서 12개만 사용하며 90~110은 실제 공정 기준이 아니다.

## 자동 테스트 범위

1. 데모 초기화, CSP, 16개 샘플 설비와 비활성 연결부 표시.
2. CSRF·다른 출처 쓰기 거절, 임의 사용자 헤더로 데모 신원 변경 불가.
3. 불완전한 운영 설정 시작 거절, 유효한 서명 없는 운영 인증 거절, 운영 샘플 자동 생성 없음.
4. 버전 충돌, 이력, 삭제 상태와 이전 버전 복구.
5. CSV의 한글·따옴표·쉼표·줄바꿈·앞자리 0 보존, 잘못된 파일·중복 열·경로형 파일명 거절.
6. XLSX 시트 처리, 문자열 출력, 수식을 실행하지 않는 텍스트 반입.

## 의존성 검토

- 직접 의존성: express 5.3.0, helmet 8.3.0, csv-parse 7.0.3, exceljs 4.4.0, yauzl 3.4.0. 전체 잠금 파일과 DEPENDENCIES.json을 제공한다.

- 설치 스크립트는 실행하지 않았다. 의존성 원문 전체를 사람이 감사하거나 별도 악성코드 엔진으로 검사하지 않았다.
