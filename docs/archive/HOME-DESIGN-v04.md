# 홈화면 디자인 16안 · 대상과 기준

디자인 대상은 캘린더가 아니라 회사 업무 포털의 홈화면이다. 핵심 콘텐츠는 설비현황·최근 인폼·업무자료·업무사이트이며 오늘 업무는 요약만 표시한다. 일정 상세와 반복 설정은 별도 캘린더로 연결한다. 기존 일정 16안은 이전 참고자료로 보존하고 홈 디자인 선호와 구분한다.

GitHub에서 반입한 Anthropic frontend-design과 Impeccable의 디자인 원칙을 참고한다. 원문·라이선스는 docs/research/upstream/에 있으며 실행기·외부 통신은 사용하지 않는다. 회사 자료 대신 동일한 가짜 설비·자료·링크로 비교한다.

기본 글자는 16px, 보조 정보는 14px 이상. 새 외부 폰트·아이콘·패키지를 추가하지 않는다. 선택하기 전 운영 홈에 특정 스타일을 적용하지 않는다.

| 번호 | 중심 | 구성 | 비교할 사용자 행동 |
| --- | --- | --- | --- |
| 01 | 통합 현황 | 왼쪽 탐색, 상태/업무 카드, 상세 레일 | 설비 선택과 맥락 확인 |
| 02 | 업무사이트 | 중앙 서비스 런처, 분류, 최근 자료 | 서비스 찾기 |
| 03 | 설비현황 | 어두운 현황 벽, 상태 필터, 알림 레일 | 이상 설비 좁히기 |
| 04 | 브리핑 | 가로 탐색, 편집형 주요 소식 | 인폼 펼쳐 읽기 |
| 05 | 업무자료 | 분류 트리, 파일 목록, 표 미리보기 | 파일 종류로 찾기 |
| 06 | 통합 맥락 | 좌우 고정 분할, 한쪽 내용 전환 | 자료·설비·사이트 비교 |
| 07 | 모듈 | 비대칭 구성, 일부 모듈 접기 | 내게 필요한 정보 선택 |
| 08 | 부서 | 인원별 담당 업무, 공용 도구 | 담당자 기준 탐색 |
| 09 | 작업 안내 | 단계별 진입, 해당 단계의 자료 | 업무 흐름 따라가기 |
| 10 | 구역 | 공간형 설비 지도, 관련 자료 | 구역·호기 기준 탐색 |
| 11 | 검색 | 설비·자료·사이트 유형별 결과 | 검색어로 시작 |
| 12 | 목적 | 전체 폭 탭으로 콘텐츠 전환 | 현황/자료/사이트 집중 |
| 13 | 디렉터리 | 접는 사이트 분류, 지원 영역 | 업무 분류로 이동 |
| 14 | 최근 변경 | 종류별 활동 피드, 선택 상세 | 바뀐 정보 확인 |
| 15 | 확인 필요 | 예외 큐, 선택 인폼, 확인 표시 | 하나씩 검토 |
| 16 | 밀도 | 고정 4분할 콘솔, 표·목록 | PC에서 동시 탐색 |

색상만 바꾼 안을 별도 UX로 세지 않는다. 각 안은 별도 구성 함수를 사용하고 데이터와 작은 요소만 공유한다. 서로 다른 진입점·정보 계층·레이아웃·대표 조작을 브라우저에서 확인한다. 프로토타입의 확인 표시·필터는 페이지 안에서만 동작하며 회사 시스템에 쓰지 않는다.
