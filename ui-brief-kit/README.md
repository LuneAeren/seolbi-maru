# UI 통역 노트 · 플랫폼 없는 시제품

`UI-통역-노트.html` 한 파일을 PC의 브라우저에서 열어 사용하는 구성을 제공합니다. 제작 플랫폼·계정·설치·AI API는 필요하지 않습니다. 개발 중 확인한 웹판은 Express 실행 후 `/ui-brief/`입니다.

현재 미리보기 브라우저는 file:// 프로토콜을 차단하므로 **단일 파일을 직접 여는 실행은 미검증**입니다. 웹판의 UI 동작과 단일 파일의 스크립트 해시/내장 자산 검사를 수행했습니다. Windows/Edge 실제 실행은 사내 반입 후 확인해야 합니다.

## 사용 순서

1. 예제의 영역을 끌어 이동하거나 오른쪽 아래 손잡이로 크기를 바꿉니다. 정확한 값은 ‘선택 속성’에서 입력합니다. 방향키는 1, Shift+방향키는 10 배치 단위입니다.
2. ‘빈 화면’ → ‘영역 그리기’로 사각형을 그려도 됩니다. 영역을 선택해 이름과 동작·요구사항을 적고 **속성 적용**을 누릅니다. 전체 요구사항도 적을 수 있습니다.
3. UI 이름을 모르면 ‘UI 용어’에서 검색합니다. 사이드바·드로어·모달·탭·아코디언·툴팁 등 16개 설명과 예시가 있습니다. 선택한 용어로 설명용 영역을 추가할 수 있습니다. 해당 기능을 운영 코드로 구현한 것은 아닙니다.
4. 종이에 그린 그림은 ‘손그림 배경 열기’에서 PNG/JPEG/WebP로 열고, 그 위에 영역과 이름을 직접 표시합니다. 5MB 이하·한 변 8,000px 이하입니다. 배경은 캔버스에 맞춰 표시되며 실제 측정 좌표가 아닙니다.
5. ‘AI 전달물 만들기’에서 `CHANGE_REQUEST.md`, `layout.json`, `preview.html` 중 원하는 파일을 내려받거나 내용을 선택해 복사합니다. 사내 AI에는 **요청서와 JSON을 함께** 전달하는 것을 권합니다. HTML에는 영역의 data-ui-id/type과 한국어 명세가 포함됩니다.
6. JSON은 ‘JSON 불러오기’로 다시 열 수 있습니다. 불러온 상태를 변경 비교의 시작점으로 삼습니다. 새로고침·닫기 전 JSON을 저장하세요. 자동 저장이나 자동 파일 쓰기는 없습니다.

## 정확히 전달되는 것

영역 ID·종류·이름·배치 X/Y/너비/높이·글자 크기·강조색·요구사항·시작 배치 대비 변경·펜 기하 좌표를 기록합니다. 배치 기준은 1000×640이며 웨이퍼 측정 X/Y와 무관합니다. 기존 좌표·원천 값·SSO/DB, 9시 노치를 유지하는 조건을 명세에 넣습니다. ER 단위·보간·균일도는 미정입니다.

**사진/손그림의 의미를 자동으로 인식하지 않습니다.** 이미지와 펜 선만으로 사내 AI가 정확하게 해석한다고 보장할 수 없습니다. 영역 이름과 메모가 의미 전달의 기준입니다. 참고 배경은 메모리에만 두고 JSON/HTML/요청서에 이미지나 원본 파일명을 포함하지 않습니다. 자유 스케치는 기하 좌표로 전달되므로 메모를 함께 적어야 합니다.

파일 내보내기는 운영 UI 자동 적용이나 AI 실행이 아닙니다. HTML은 배치와 명세를 확인하는 문서이며 편집기와 모든 장식/더미 표를 동일하게 복제하지 않습니다. Streamlit은 설치 버전의 열·컨테이너·기존 그래프 코드에 명세를 연결해야 합니다. 자동 코딩·Streamlit 어댑터는 없습니다.

## 와처가 있는 경우

내려받은 요청서/JSON을 사내 와처 감시 폴더에 직접 넣습니다. 와처의 제품·감시 경로·처리 규칙은 확인하지 않았으므로 자동 연결은 없습니다. 드래그 매 순간 AI를 호출하지 않고 저장한 명세만 입력으로 사용하세요. 실제 계정·자료·주소·환경 보고서는 외부 저장소로 보내지 않습니다.

## 구현/보안 경계

새 npm/Python 패키지를 추가하지 않았습니다. UI 편집기는 네트워크 호출·로컬 자동 저장·외부 자산·AI SDK·임의 코드 실행을 사용하지 않습니다. 웹판에는 connect-src none, frame-src none을 적용합니다. 동적 배치 스타일과 로컬 blob 이미지에 필요한 허용은 /ui-brief/에만 한정하고 기존 포털의 CSP는 유지합니다. 단일 파일은 내장 스크립트의 SHA256 CSP를 포함합니다. 패킷 차단 실측이나 악성코드 부재의 포괄적 보증은 아닙니다.

JSON은 버전·종류·고유 ID·크기·좌표·수량을 검사하고 문자열/색상을 제한합니다. 내려받은 HTML은 사용자 글을 이스케이프하며 실행 스크립트가 없습니다. 영역 최대30개·펜50획·획당500점·JSON입력500KB, 실행 취소50단계입니다. 여러 사용자의 공동 편집·충돌 처리·자동 저장은 없습니다.

## 개발자/사내 AI 파일 지도

- `public/ui-brief/core.js`: 정규화·차이·한국어 요청서·JSON/HTML 생성.
- `public/ui-brief/app.js`, `index.html`, `style.css`: 편집기와 용어 사전. 편집기를 수정하면 단일 파일을 다시 생성합니다.
- `scripts/build-ui-brief.js`: 원문 CSS/JS를 한 HTML에 내장하고 스크립트 해시를 생성. `node scripts/build-ui-brief.js`로 실행합니다.
- `test/ui-brief.test.js`: 명세 보존·잘못된 입력/주입 방어·단일 파일 해시·웹판 CSP 범위 회귀 검사.
- `examples/`: 가짜 UI를 브라우저에서 실제 이동/수정해 만든 전달물 3개. 이미지 다운로드 결과를 가장한 파일이 아니라 전달 창에서 생성된 내용을 보관한 예제입니다.
- `docs/UI-BRIEF-CHECKS.json`: 실제 UI 검증 범위와 미검증 항목.
