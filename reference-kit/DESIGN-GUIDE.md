# 사내 AI에 전달할 디자인 적용 지침

사용자가 `/home-designs/`에서 고른 번호와 요소를 먼저 확인한다. 색상·표·내비게이션·정보 순서를 섞어 선택할 수 있다. 선호안이 정해지기 전 회사 운영 화면을 한 스타일로 확정하지 않는다.

- 디자인 대상은 홈화면이다. 설비현황·최근 인폼·업무자료·업무사이트의 우선순위와 탐색을 다르게 비교한다. 일정 상세·장소·반복 설정은 별도 캘린더에서 처리한다.
- 체크리스트·인폼·과거 이력은 선택한 업무의 상세나 별도 화면으로 분리한다.
- 데스크톱 기본 본문/조작은 16px, 보조는 14px 이상. 글자를 줄여 기능을 밀어 넣지 않는다.
- 표에는 정렬·검색·고정 머리글·제한된 스크롤을 둔다. 배정 카드의 자세한 근거는 검토 단계에서만 펼친다.
- 상태를 색만으로 구분하지 않고 이름과 함께 표시한다. 포커스·라벨·빈 결과·오류·저장 중 상태를 구현한다.
- 모든 파일과 폰트·아이콘은 사내에서 제공한다. 외부 CDN·통계·AI 호출을 넣지 않는다.
- 디자인 프로토타입의 가짜 데이터와 실제 배정 알고리즘을 섞지 않는다. 실제 계산은 reference-kit/planner.js와 회사 입력 어댑터가 담당한다.
- 새 프레임워크 설치나 원본 저장소 CLI 실행을 디자인 적용의 전제 조건으로 삼지 않는다.

출처와 확인 커밋은 docs/research/DESIGN-REFERENCES.md에 있다. 참고 자료는 지침과 아이디어로 사용했고 프로토타입 코드는 이 저장소에서 직접 작성했다.
