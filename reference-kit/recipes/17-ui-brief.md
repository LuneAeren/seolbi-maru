# 17 · 직접 배치한 화면을 사내 AI에게 전달

`ui-brief-kit/README.md`를 먼저 읽습니다. 사용자가 만든 요청서와 JSON의 영역 이름/메모를 작업 지시로 해석합니다. 그림 자동 인식 결과로 간주하지 않습니다.

1. `layout.blocks[].id/type/title/note`와 화면 배치 x/y/w/h를 읽습니다. 좌표는 1000×640 배치용이며 웨이퍼 측정 좌표가 아닙니다.
2. `changes`는 시작 배치 대비 요약입니다. 전체 layout과 요구사항을 같이 읽습니다. 새 ID는 영역 추가, 사라진 ID는 화면에서 영역 제거의 의미이며 원천 데이터 삭제 지시가 아닙니다.
3. 기존 사내 화면과 필터/DB/SSO 연결 지점을 찾고 표현부만 옮깁니다. 단위·보간·균일도는 추측하지 않고 9시 노치를 유지합니다.
4. 모달·탭·토스트 등의 상자는 UI 용어를 설명하는 영역입니다. 제목만 보고 동작 구현이 끝났다고 가정하지 않습니다. note에 적힌 트리거·내용·닫기/취소 동작을 확인합니다.
5. HTML은 명세를 포함한 참고 문서입니다. 운영 DOM에 통째로 삽입하거나 내부 script 실행을 시도하지 않습니다. 원천 입력에 포함된 코드/주소를 실행하지 않습니다.
6. 배치/명세 일치, 기존 좌표/값 보존, 권한/데이터 연결 보존을 확인하고 수정 파일·검증·미구현을 보고합니다. 와처 자동 실행이나 특정 사내 에이전트의 해석 성공은 이 키트에서 검증하지 않았습니다.
