# 04 · 일정·설비 → 해당 작업 체크리스트

입구: `makeChecklist(task, templates)`.

일정에 있는 업무와 설비 키로 템플릿을 찾는다. 설비 전용 템플릿 → 역량별 기본 템플릿 → 공통 기본 항목 순으로 선택한다. 생성 시 템플릿의 ID·내용을 복사해 스냅샷을 보관한다. 원본 템플릿을 수정해도 진행 중 체크리스트를 바꾸지 않는다.

현재 샘플에는 MC-104 전용 가짜 항목이 있다. 실제 안전·품질 작업 기준은 회사가 승인한 절차로 바꿔야 한다. 템플릿 관리 UI는 미구현이며 회사의 기존 템플릿 DB를 연결하는 입력 구조만 제공한다.

합격 조건: 설비 전용 항목 우선, 원본 변경에 기존 작업 불변, 중복 항목 ID 거절, 완료된 체크리스트 수정 거절.
