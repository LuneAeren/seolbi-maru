# 07 · 교대 인수인계 요약·출력

입구: `handover(state, day)`.

확정일을 기준으로 미완료 업무, 완료 인폼, 부분 진행 체크리스트를 모은다. 과거 원래 날짜와 이월 후 확정일을 구분한다. 화면에서는 요약을 먼저 보여주고 상세 기록은 필요할 때 연다.

예제는 브라우저 인쇄와 PDF 저장 대화상자를 사용한다. 서버가 외부 PDF 서비스에 자료를 보내지 않는다. 저장 경로와 문서 보안은 회사 정책을 따른다.

합격 조건: 기준일 변경 시 다른 날짜의 작업 제외, 이월 작업 포함, 미완료 항목 누락 없음, 출력에 조작 버튼 제외.
