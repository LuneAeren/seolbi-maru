# 02 · 역량·가중치로 배정 초안

입구: `planDay({tasks, staff, bookings, day, includeOverdue})`.

1. 예정일과 미완료 여부를 필터링한다.
2. 우선순위·마감·필요 역량으로 업무 순서를 고정한다.
3. 자격 미달·휴무·하루 용량·휴게·사람 일정·설비 일정·마감 충돌을 후보에서 제외한다.
4. 남은 후보의 부하를 가중치로 나누어 비교한다.
5. 선정 이유와 미배정 사유를 함께 표시한다.

새 알고리즘에 회사의 근무 규칙을 섞기 전에 순수 함수 테스트를 유지한다. 가중치를 높여도 자격·작업시간 한계를 우회하지 않는다. 점수는 직원 평가가 아닌 명시적으로 입력한 배분 설정이다. 전역 최적화·이동·준비·선행 작업·다인 작업은 추가 설계 범위다.

합격 조건: 같은 입력이면 같은 결과, 가중치 차이 반영, 적격자 없음 표시, 용량·휴게·마감·설비 중복 위반 없음.
