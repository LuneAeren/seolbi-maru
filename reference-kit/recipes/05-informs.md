# 05 · 체크 완료 → 인폼 한 번 생성

입구: `checkItem`, `completeTask`.

각 체크의 결과·메모·작성자를 저장하며 설비 이력도 함께 기록한다. 모든 항목을 확인하기 전에는 작업 완료를 허용하지 않는다. 완료 시 체크리스트 잠금·작업 완료·일정 완료·인폼 생성·설비 이력을 하나의 트랜잭션으로 저장한다.

운영 DB에는 인폼의 source_task_id에 UNIQUE 제약을 둔다. 같은 완료 요청이 다시 와도 기존 인폼을 돌려주고 새 인폼을 만들지 않는다. 수정이 필요하면 잠금을 조용히 풀기보다 정정 이력을 남기는 별도 업무를 설계한다.

합격 조건: 미완료 항목 있으면 완료 거절, 완료 반복에도 인폼 1개, 메모가 요약에 포함, 완료 후 체크 수정 거절.
