# 16 · 기존 Streamlit 선그래프·ER 맵의 표현 바꾸기

## 목표

좌표/DB/SSO를 다시 만들지 않고 `streamlit-kit/ER-REFERENCES.md`의 ER 6종·선그래프 4종 중 선택한 표현만 기존 앱에 적용한다. 노치는 9시 고정이다. 단위·보간·균일도 계산식은 미정이며 변경하지 않는다.

## 사내 AI 작업 순서

1. 선택 번호의 SVG·JSON·Markdown을 읽고 기존 렌더러와 연결 지점을 찾는다. 실제 데이터·주소를 외부로 보내지 않는다.
2. 설치된 라이브러리 버전/지원 함수를 사내에서 확인한다. 기존 데이터 읽기/좌표/계산/권한 코드는 유지한다.
3. 기존 좌표 원점·X/Y 방향·반경·색상 범위를 확인한다. 예제 정규화 13점과 90~110은 운영 규칙이 아니다. 반전/회전/보간/중복점 집계를 임의 추가하지 않는다.
4. 선택된 화면만 생성한다. 단계별 시간을 측정한 뒤 필요한 부분에 한해 캐시나 상세 지연 생성을 적용한다. 사용자 권한과 원천 스냅샷 버전을 구분한다.
5. 기존과 새 화면의 동일 데이터 값을 대조한다. 미측정과 0, 누락 선 구간, 1:1 축, 9시 노치, 비교 화면의 공통 색상 범위를 확인한다.

## 전달 파일

`er_reference.py`, `er_reference_app.py`, `er-previews/선택번호.{svg,json,md,py,html}`, `test_er_reference.py`, `inspect_environment.py`. HTML/CSS는 Express의 `/er-reference/` 또는 파일로 열 수 있다. `.py`는 정적 SVG를 보여주는 참고 코드이며 화면 클릭 기능을 완성한 어댑터가 아니다. 선택적 Plotly 단일 맵 함수도 회사 버전에서 별도 검증해야 한다.

## 완료 보고

수정 파일, 기존 데이터 경로 보존 여부, 시각/값 검증, 전후 성능 실측, 미구현을 분리해 보고한다. 개발 PC의 Python 검사·정적 HTML 검수를 실제 Streamlit/Plotly 실행 성공으로 표현하지 않는다. 새 패키지나 외부 통신을 추가하지 않는다.
