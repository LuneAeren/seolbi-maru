# 06 · 인폼이 없어도 설비 이력 조회

입구: `equipmentHistory`.

일정 확정·체크 변경·작업 완료 같은 이벤트를 인폼 저장소와 구분해 보관한다. 조회는 인폼 ID가 아니라 정규화한 설비 키를 기준으로 한다. 과거 원천 작업 기록에 인폼이 없어도 검색 결과가 나오도록 합집합으로 구성한다.

기존 회사 이력 DB를 연동할 때 시간대·설비 별칭·호기명 변경을 정규화하고 출처를 표시한다. 실제 이력을 GitHub나 외부 검색 도구로 옮기지 않는다.

합격 조건: 인폼 없는 과거 이벤트 표시, 체크 기록 추적, 설비별 필터, 기록 시각·작성자·출처 확인.
